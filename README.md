# Predicting Heart Attack Risk Using Cholesterol Levels: A Machine Learning Approach

## 📌 Overview

This project explores the correlation between cholesterol levels and the risk of heart attacks using machine learning techniques. By analyzing clinical data, we aim to build a predictive model that can assist in early detection and prevention of cardiovascular events.

The workflow includes:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Model training using supervised learning algorithms
- Performance evaluation and model selection
- Interpretation of feature importance related to cholesterol and other risk factors

## 🧠 Objectives

- To understand the role of cholesterol in heart attack prediction
- To build an accurate predictive model using ML techniques
- To evaluate model performance using metrics such as accuracy, precision, recall, and ROC-AUC

## 🧰 Tech Stack

- **Language:** Python
- **Libraries:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Modeling Techniques:** Logistic Regression, Decision Trees, Random Forest
- **Dataset:** Clinical heart disease dataset with cholesterol values
- **Visualization:** matplotlib, seaborn

## 📂 Folder Structure & Files

- `heart_attack_prediction.ipynb` - Jupyter notebook containing complete code
- `dataset.csv` - The cleaned and preprocessed dataset used
- `research_paper.pdf` - A brief research report on methodology and findings
- `results` - Charts and visualizations from EDA and model evaluation
