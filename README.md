# Risk-Assessment-of-Myocardial-Infarction-Through-Cholesterol-Analysis


## 📌 Project Overview

This project aims to **predict the risk of heart attacks** based on an individual's **cholesterol levels** and associated clinical parameters using supervised machine learning models. The primary goal is to assist healthcare professionals in identifying high-risk individuals early, enabling timely intervention and prevention.

## 🚀 Key Features

- Cholesterol-centric heart attack risk prediction
- Data preprocessing and exploratory data analysis
- Training and evaluation of multiple machine learning models
- Model comparison based on accuracy, precision, recall, and F1 score
- Visualization of model performance
- Deployment-ready code structure

## 🧠 Technologies Used

- **Python**
- **Pandas, NumPy** – Data manipulation
- **Matplotlib, Seaborn** – Data visualization
- **Scikit-learn** – Machine learning models
- **Jupyter Notebook / Colab** – Development environment

## 📂 Dataset

The dataset includes various features relevant to cardiovascular health such as:

- Age  
- Gender  
- Resting Blood Pressure  
- Serum Cholesterol (mg/dl)  
- Fasting Blood Sugar  
- ECG Results  
- Maximum Heart Rate Achieved  
- Exercise-Induced Angina  
- Oldpeak (ST depression)  
- Target (1 = Heart Attack, 0 = No Heart Attack)

## ⚙️ Model Workflow

1. **Data Cleaning** – Handling missing values and outliers  
2. **EDA** – Understanding feature distribution and correlations  
3. **Feature Selection** – Identifying the most relevant predictors  
4. **Model Training** – Logistic Regression, Random Forest, SVM, etc.  
5. **Evaluation** – Accuracy, Confusion Matrix, ROC Curve  
6. **Conclusion** – Best model chosen based on performance

## 📈 Results

- Best-performing model: **Random Forest Classifier**  
- Accuracy: **94%**  
- F1 Score: **0.93**
